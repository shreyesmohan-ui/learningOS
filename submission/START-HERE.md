## What distinguishes this project

1. A real PostgreSQL engine checks query results, not a model's opinion.
2. Graduated help separates a conceptual nudge from a worked solution.
3. Unaided checkpoints remove hints and expose the difference between completion and independence.
4. Two data fixtures catch some answers that merely hard-code the sample result.
5. Evidence exports retain assistance flags, timing, phase, and provider provenance.
